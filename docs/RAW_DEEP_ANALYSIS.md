장기 가정의 확실성이나 원문 전체 감사, 매수 가능성을 뜻하지 않는다.
미공개 royalty, 별도 보증·차입, 미래 수익률 등은 추정 또는 unknown으로
남긴다. INVESTIGATE는 별도 투자 승인 게이트다. 이번 34개에는 매수 승인과
포지션 배정을 부여하지 않았다.

## 계산 규칙

- USD billion 또는 KRW trillion, 주식은 million. 한국 가격환산은
  `KRW trillion / million shares × 1,000,000`, 미국은 ×1,000이다.
- 현재 가격과 날짜가 다른 공시 주식 수는 참조값이다. 회사 시가총액을
  시세 제공업체 숫자에서 그대로 가져오지 않는다. 우선주·ADS·LLC 경제지분을
  표시하며 분모 민감도를 별도 보존한다.
- 미래 owner cash margin은 SBC 포함 경제적 영업마진의 세후액에서
  전체 재투자, 운전자본·금융 필요자본, 이자·순부채상환 현금비용을 연결한다.
  유지 Capex를 임의로 작게 골라 실제 투자부담을 지우지 않는다.
  HQ·발사프로그램 등의 명시적 추가 투자경로는 통상 성숙마진 밖의 추가 부담이다.
- 기존 SBC는 경제적 보상비용이다. 같은 미래 보상을 현금비용과 미래
  연간 희석으로 두 번 차감하지 않는다. 실제 공시의 자본화 SBC나 미행사
  권리 간 중복을 미확인한 경우 완전 owner FCF라고 주장하지 않는다.
- FCFE 모형이므로 이자·정상 부채서비스를 비용에 포함하고 opening net cash를
  다시 가치에 더하지 않는다. 개시 현금은 유동성 시험에만 사용하므로
  초과현금 배분가치가 포함되지 않은 보수적 영업권 가치다. 별도 SOTP나
  우선권 조정은 해당 영업현금 범위에서 제외한 권리만 적용한다.
- 초기 현금 적자는 기본 계산에 음수로 보존한다. 기본 PV는 기존 주주가
  필요한 자금을 제공하는 추가출자 등가이다. 대체 증자 모형은 현금을 먼저
  사용하고 모자란 금액에만 가정한 발행가로 새 주식을 발행한다. 대체 모형은
  양수 배분과 종료가치만 희석하며 동일 음수 추가출자를 재차 차감하지 않는다.
  이 두 모형은 합산하는 손실이 아니다.
- 역산은 첫 12개월 추정매출과 Base 현금경제를 고정하고 이후 9년의
  성장 요구를 계산한다. 작은 초기매출의 위성기업은 절대 매출·현금 경로에
  성장 스트레스를 적용한다. 실제 시장 기대의 유일한 해나 TTM CAGR가 아니다.
- IRR은 중간 현금과 종료가치를 포함한다. 비전형적 현금 부호의 복수 해를
  숨기지 않는다. 실패확률은 역으로 계산한 손익분기 문턱과 구분한다.

## 검증·재현

```bash
python -m harness.deep_report --check
python -m harness.validate
bash scripts/check_harness.sh
```

`jsonschema`가 필요하다. 작성된 입력을 변경한 후 재생성하려면
`python -m harness.deep_report --write`를 실행하고 검증한다. 이 명령은
외부 게시나 거래를 하지 않는다. 다만 이 날짜 연구의 입력을 의미 있게
바꿀 때에는 새 날짜/실행 ID를 만들어 과거 판단을 보존하는 것이 원칙이다.

검증은 산술·권리 변환·원본 해시·재현성을 확인한다. 미래 가정이 맞는지,
비공개 계약 조건이 확인됐는지, 모든 공시가 독립 감사됐는지를 보증하지 않는다.
