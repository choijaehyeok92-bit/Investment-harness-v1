# 투자철학 계량화 스크리닝 루브릭

`outlier-expectation-gap-harness`의 투자철학을 **직접 종목을 스크리닝할 수 있는 수치 기준**으로 변환한 것이다.

- 8개 도메인 · **32개 지표** · 9개 Hard Veto
- 지표별 **0~4점**, 도메인 점수 = (획득합 / 평가된 지표 만점) × 100 × 결측할인
- 요구수익률 **9%** · 가중치는 `config/strategy.json` 원본과 동일

## 파일

| 파일 | 용도 |
|---|---|
| `rubric.json` | 기계가 읽는 기준표(구간·veto·판정규칙) |
| `score.py` | 계산기. `python score.py inputs.json` |
| `template.json` | 빈 입력 양식 |
| `examples/*.json` | 실제 데이터 검증 사례 4건 |

```bash
cp template.json MYSTOCK.json      # 아는 값만 채우고 나머지는 null로 둔다
python score.py MYSTOCK.json
```

### 구간을 이렇게 잡은 이유

- **D4M1 증분 ROIC 8%가 1점 하한**: 요구수익률 9% 바로 아래다. 허들을 못 넘는 재투자는 성장이 아니라 가치파괴다.
- **D7M1 안전마신 0%가 1점**: 원칙2. 좋은 기업이어도 기대차가 없으면 투자가 아니다.
- **D8M2 Bull 배수 1.0 미만 = 0점이자 Hard Veto 확정**: Bull조차 현재가를 밑돌면 어떤 시나리오로도 정당화되지 않는다.
- **D1M3 정상화 배수는 양방향 구간**: 최근 성장률이 5년 평균의 1.5배를 넘으면 오히려 감점한다. 피크를 구조적 성장으로 오인하는 것이 이 전략의 최대 오류원이다.
- **D7M4 배수는 최고 4점이어도 단독 탈락 사유가 아니다**: 금지된 지름길(고PER 단독 탈락)을 막기 위해 가중을 낮게 뒀다.

## 3. 판정 순서

```
1) Hard Veto      확정 ≥1 → REJECT
                  조사 ≥1 → 최대 WATCH, 비중 0%
2) Coverage       평가 도메인 가중합 < 100 → INCOMPLETE (점수를 등급으로 해석하지 않는다)
3) SCREEN_OUT     Bull배수 < 1.0  |  비대칭 < 0.5  |  총점<60 AND 안전마진<0
4) SCREEN_IN      총점 ≥ 70 AND 안전마진 > 0 AND 비대칭 ≥ 1.5   (동시 충족)
5) WATCH          나머지
```

분류: 90+ Exceptional Outlier(≤10%) · 85+ Core(6-8%) · 75+ Emerging(2-4%) · 65+ Starter/Watch(1-2%) · 그 외 Reject(0%)

## 4. 모르는 값 처리

**빈칸을 낙관적 추정으로 채우지 않는다.** `null`로 두면:

1. 해당 지표는 도메인 분모에서 **제외**된다 (없는 점수를 0점으로 만들지 않는다)
2. 도메인 점수에 **결측할인**이 붙는다: `× (1 − 0.5 × 미확인/지표수)`
   - 4개 중 1개 미확인 → ×0.875 · 2개 → ×0.75 · 3개 → ×0.625
3. 한 도메인의 지표가 **전부** 미확인이면 그 도메인은 coverage에서 빠지고 → 총점은 INCOMPLETE

## 5. 실제 데이터 검증

기존 하네스가 이미 심사한 NVDA와, 직접 역산 DCF를 돌린 P1 3종목으로 돌려봤다.

| 종목 | 총점 | 할인 전 | coverage | 신뢰도 | 판정 |
|---|--:|--:|--:|--:|---|
| NVDA | 50.80 | 72.55 | 85/100 | 0.41 | INCOMPLETE |
| SNPS | — | — | 35/100 | 0.22 | INCOMPLETE |
| CDNS | — | — | 35/100 | 0.22 | INCOMPLETE |
| TER | 27.23 | 39.29 | 35/100 | 0.22 | **REJECT** (veto 확정) |

읽는 법 세 가지:

1. **TER은 점수를 보기도 전에 REJECT다.** Bull 가치 311.25달러 < 가격 372.06달러가
   `price_requires_unrealistic_bull_case`의 확정 조건을 충족한다. `Hard Veto > Score`가 작동한 것이다.
2. **NVDA조차 INCOMPLETE다.** 이 저장소에서 가장 많이 조사된 종목인데도 32개 중 19개가 미확인이고
   구조적 리더십 도메인(가중 15)은 지표가 하나도 없다. 루브릭이 **무엇을 더 모아야 하는지**를 지목한다.
3. **NVDA의 최저 도메인은 기대차 29.2점**이다. 기존 하네스의 판단(8/15, 가장 약한 고리)과 방향이 일치한다.

### 검증 중 발견해 고친 결함 2건

- **분류가 INCOMPLETE를 무시했다**: coverage 85/100인 NVDA에 "Reject" 등급이 붙었다. 점수 미확정인데 등급을 표시하면 오독을 부른다 → coverage 100 미만이면 분류도 INCOMPLETE로 고정.
- **결측 패널티가 변별력을 잃었다**: 전역 합산(0.75/개, 상한 12점) 방식은 지표가 32개라 결측이 16개만 넘어도 전부 상한에 붙었다. SNPS와 TER이 똑같이 −12를 받았다 → 도메인별 결측 비율 할인으로 교체.

## 6. 알려진 한계

- **D7M2(기대 부담률)의 분모를 피크 성장률로 쓰면 왜곡된다.** TER은 2분기 매출 +104%라 분모로 쓰면 만점이 나오지만 실제로는 사이클 정점이다. **반드시 3년 CAGR 또는 정상화 성장률**을 쓰고, 피크가 의심되면 `null`로 두는 편이 낫다. (검증 사례 전부 `null` 처리했다.)
- **D2M1(NRR)·D3M4(설치기반)·D5M4(가이던스 달성률)는 미공시 기업이 많다.** 업종에 따라 구조적으로 unknown이 된다.
- **구간은 범용 기준이다.** 규제 유틸리티·은행·REIT처럼 자본구조가 다른 업종은 D4·D6 구간을 따로 잡아야 한다.
- **정성 판단을 대체하지 않는다.** 32개 지표가 만점이어도 Hard Veto가 확정이면 REJECT다.

## 7. 금지된 지름길

- PER가 높다는 이유만으로 탈락 금지 (D7M4는 단독 탈락 사유가 아니다)
- PER가 낮다는 이유만으로 통과 금지
- 주가가 올랐다는 이유만으로 탈락 금지
